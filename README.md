Podorozhnuky — is a web platform for travelers and travel enthusiasts.(BACKEND)

The website allows users to share their travel stories, discover inspiration for new adventures, and connect with other travelers. Users can create personal profiles, post stories, explore others’ journeys, and find like-minded people who love discovering new places. ❤️
The mission of the project is to unite people through the love of travel, support the exchange of authentic experiences, and inspire new adventures.

✨ Main Features

 - Share Travel Stories — Users can create and publish their own travel stories.
 - Discover & Explore — Browse inspiring stories from other travelers, find new routes, destinations, and adventures.
 - Community — Connect with other travelers, follow, and interact with like-minded adventurers.
 - User Profiles — Personal profiles to save your stories, favorites, and shared journeys.
 - Navigation by Sections — Easy-to-use sections such as “Stories,” “Travellers,” “Profile,” “Register / Login.”
 - User-Friendly UI/UX — Clean and intuitive design for smooth navigation and enjoyable experience.

📥 Installation

Clone the repository
```
git clone https://github.com/DDenysKoval/Travellers_Back.git
```

Navigate to the project folder and install dependencies
```
cd Travellers_Backt
npm install
```

🚀 Usage

To run the application in development mode:
```
npm run dev
```

The app will be available at: http://localhost:3000

🛠️ Tech Stack

 - JavaScript
 - Node.js
 - Express.js
 - Mongodb
